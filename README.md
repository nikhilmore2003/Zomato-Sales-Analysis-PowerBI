# 📌 Project Overview

This project presents an interactive Power BI dashboard built using a Zomato restaurant and order dataset.

The dashboard enables stakeholders to analyse restaurant performance, customer ordering behaviour, city-wise sales, yearly trends, food category distribution, and key business metrics through interactive visualizations.

---

# 🎯 Business Problem

Food delivery platforms generate enormous amounts of transactional and customer data.

Without an interactive reporting system, analysing sales performance, customer demand, and restaurant growth becomes challenging.

This dashboard transforms raw business data into meaningful insights that support better operational and strategic decision-making.
